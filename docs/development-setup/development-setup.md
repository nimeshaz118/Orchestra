- `.nvmrc` pins Node.js 26.13.0.
- `.python-version` pins Python 3.13.17.
- `global.json` pins the .NET 10 SDK patch used by this checkout.
- `src/ai-service/requirements.txt` pins FastAPI.
- The frontend `package-lock.json` will lock the React, TypeScript, Vite, and other npm dependency versions when the Vite application is scaffolded.

## Windows local setup

Install the x64 versions of Node.js, Python, and Docker Desktop unless the device architecture requires another official package.

### Node.js

Install Node.js 26.13.0 LTS, then open a new terminal and verify:

```powershell
node --version
npm --version
```

Expected Node.js output:

```text
v26.13.0
```

### .NET SDK

Install the .NET 10 LTS SDK and verify from the repository root:

```powershell
dotnet --version
dotnet --list-sdks
```

The selected SDK must satisfy `global.json`.

### Python and FastAPI

Install Python 3.13.x, open a new terminal, and verify:

```powershell
python --version
```

Create the AI-service virtual environment and install the pinned FastAPI version:

```powershell
Set-Location src/ai-service
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -c "import fastapi; print(fastapi.__version__)"
```

### Docker Desktop and Compose

Install Docker Desktop for Windows using the WSL 2 backend where available. Start Docker Desktop, accept its terms, and verify:

```powershell
docker --version
docker compose version
```

PostgreSQL will run from the repository's Docker Compose configuration after that configuration is added. The required image version is PostgreSQL 18.x.
